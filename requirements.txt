# Samruddhi Fire QMS — runtime dependencies
#     pip install -r requirements.txt
#
# The dependency SET is derived from the app's actual imports, not from a
# `pip freeze` of a system Python — INTRODUCTION.md §5.7. Only these four are
# imported by application code:
#
#     flask          every module
#     markupsafe     address.py escapes with markupsafe.escape
#     pymysql        db.py — MySQL persistence
#     dotenv         db.py — reads .env
#
# The VERSIONS are pinned so a clone reproduces a known-good environment rather
# than whatever PyPI resolves to that morning. They are the versions the
# 523-test suite is verified against — `python -m pytest -q` in a .venv built
# from this file, with openpyxl added (see the dev block below).
#
# Pins are only ever RAISED to a version the suite has been verified on, never
# lowered: a pin below the installed version turns `pip install -r` into a
# silent downgrade of whatever else shares that interpreter.
#
# Supported: CPython 3.10 to 3.14. Last verified on CPython 3.14.3 (Windows).
# A single build number is wrong here — this repo is cloned on two machines
# with different Pythons, and the app pins no interpreter-specific behaviour.
